# 🌦️ Weather Data Visualization using API Integration

A simple Python project that integrates with the **OpenWeatherMap API** to fetch live weather forecast data and visualize temperature trends using **Matplotlib**.

---

## 🚀 Features
- Fetches real-time 5-day/3-hour forecast data.
- Visualizes temperature variation over time.
- Demonstrates clean API integration and data handling.

---

## 🛠️ Tech Stack
- **Python 3**
- **Requests** – for API calls
- **Matplotlib** – for data visualization
